API Reference

Video / Image 管理機能で利用する FastAPI エンドポイントの概要です。

🔗 Base URL

http://localhost:5000

📚 Available Endpoints

Folder / JSON

  • GET /management/folder/view/files - 指定フォルダのファイル一覧を生成
  • GET /management/json/list/files - JSON から一覧を取得
  • GET /management/folder/check/json - 既存 JSON の存在確認

Thumbnail / File View

  • GET /management/file/create/thumbnail - サムネイル生成と返却
  • GET /management/file/view/thumbnail - サムネイル画像配信
  • GET /management/file/view/thumbnail/exists - 既存サムネイル確認
  • GET /management/file/view/details - ファイル詳細取得

Rename / Edit

  • POST /management/file/changename/single - 単体リネーム
  • POST /management/file/changename/several - 複数リネーム

curl "http://localhost:5000/management/file/create/thumbnail?id=1&jsonPath=C%3A%5C%5Cpath%5C%5Cfile_list.json"
