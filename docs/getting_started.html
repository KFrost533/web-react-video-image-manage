Getting Started

Video / Image 管理アプリをローカルで動かすための最短手順です。

📋 Prerequisites

  • Node.js (v16 以上推奨)
  • Python (v3.10 以上推奨)
  • Git

🚀 Installation

  1. リポジトリを取得: 
    git clone <this-repository-url>
  2. プロジェクト直下へ移動: 
    cd web-react-video-image-manage
  3. 一括セットアップ: 
    npm run setup

▶️ Running the Application

  1. バックエンド + フロントエンドを同時起動: 
    npm run start:all
  2. ドキュメントを開く: 
    npm run docs

🧭 Basic Workflow

  1. Video または Image の一覧画面を開く
  2. Base Path と Relative Path を指定して検索
  3. サムネイル確認、絞り込み、詳細表示、必要に応じてリネーム

⚠️ Troubleshooting

  • サムネイルが表示されない場合は backend が起動しているか確認
  • 依存関係エラー時は npm run setup を再実行
  • Python 関連エラー時は仮想環境と requirements の再インストールを確認
