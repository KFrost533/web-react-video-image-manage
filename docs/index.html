🎉 Welcome to Video & Image Management Docs

このドキュメントは、動画と画像を一覧・検索・タグ管理・詳細確認するための Web アプリ向けに構成されています。セットアップ、API、運用方針をこのサイトで確認できます。

🚀 Quick Start

まずは 3 ステップでローカル環境を起動できます。

📋 Next Steps:

  1. 依存関係を準備: npm run setup
  2. アプリを起動: npm run start:all
  3. ドキュメントを再表示: npm run docs

💡 運用メモ: 先に backend を起動し、続いて frontend を起動するとサムネイル取得の確認がしやすくなります。

📋 主要機能

  • ✅ 動画・画像のフォルダスキャンと一覧表示
  • ✅ サムネイル生成・表示（キャッシュ対応）
  • ✅ 拡張子、サイズ、タグ、キーワードによる絞り込み
  • ✅ ファイル詳細画面への遷移
  • ✅ 複数ファイルのリネーム支援

🎯 利用シーン

🎬
動画アーカイブ管理: 大量の動画を一覧で確認し、必要なファイルへ素早くアクセス
タグと検索で見たい素材を即座に抽出
🖼️
画像素材整理: サムネイル中心で画像を比較し、管理作業を短縮
フォルダ粒度での運用に最適化
🛠️
ローカル運用: FastAPI + React によるシンプルな管理基盤
日常的なメディア整理作業を軽量に継続可能
